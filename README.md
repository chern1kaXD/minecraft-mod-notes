 # minecraft-mod-notes
Хранилеще настроек и идей по сборки модов
## Паспорт сборки

- Версия Minecraft: 1.21.1
- Ядро/загрузчик: Fabric
- Версия загрузчика: 0.16.15
- Количество модов: 50
- Ключевые моды: Create, JEI, Sodium
- Особенности сборки: акцент на автоматизацию, оптимизация для слабых устройств
- Инструкция по установке: скачать Fabric Loader нужной версии для Minecraft 1.21.1, распаковать моды в папку mods
